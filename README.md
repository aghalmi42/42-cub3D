# cube3d

## DESCRIPTION
The Cub3D project consists of creating a simple graphics engine in C using the raycasting technique, similar to the game Wolfenstein 3D.
It allows rendering a 3D view from a 2D map and implementing movement, textures, and basic interactions in an immersive environment.

## Instructions

``
make
``

``
./cub3D map.cub
``

``
./cub3D_bonus map.cub
``

To move, use **W, A, S, D**, and to open doors use **E**.
To control the camera, use the **mouse** or the **left and right arrow keys**.

For check memory allocation use : 

``
Valgrind ...
``
